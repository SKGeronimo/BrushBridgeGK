How it works & limitations

A .kpp file is actually a PNG image with brush settings stored in a hidden text chunk. This tool extracts the brush tip and basic settings, then writes a Photoshop ABR (v2, sampled brush) file.

Preserved: brush tip shape, size, spacing, name.

Lost: Krita dynamics (pressure curves, jitter, dual brush, textures, etc). ABR v2 is a simple format. For richer conversion you'd upgrade buildAbr() to emit ABR v6/v7.
